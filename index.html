            ⚡ 次毫秒同步渲染
          

          

            不同於傳統 Mermaid.js 須依賴瀏覽器 DOM 測量與非同步執行，Pele 是純 JavaScript 同步實作，單圖渲染僅需 0.3 ~ 1.5 毫秒，速度提升高達 100~500 倍。
          

        

        

          

            📦 零依賴極致輕量
          

          

            無任何外部執行時期相依性（Zero Dependencies），生成的 SVG 乾淨標準，不帶任何龐大的第三方函式庫包袱，可無縫嵌入任何 Web、Electron 或行動應用程式。
          

        

        

          

            🎨 CSS 變數原生主題
          

          

            採用 --pele-bg, --pele-fg 等 CSS 變數定義顏色。更換主題只需更換 CSS Class，圖形即刻適應，完全不需重新呼叫渲染！
